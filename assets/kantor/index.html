    Riwayat aktivitas

      Penampilan

      Cara pakai

      Kantor 2 lantai: lantai 1 (lobby, studio, open workspace, ruang rapat, pantry, lounge, taman) dan lantai 2 (Ruang Pimpinan, DevOps · NOC, ruang server, Divisi Programmer, lounge, teras). Tombol Lantai 1 / Lantai 2 / Terpisah di kanan atas memilih lantai yang dilihat. Klik orang atau nama anggota untuk melihat detailnya (termasuk skill divisinya). Di tab Tim, tombol 🧰 di kartu divisi membuka skill wajib, skill opsional, dan alat tiap divisi. Tab Keterangan menjelaskan arti status, warna layar, gerakan, ruang, dan sudut kamera. Tab Pegawai untuk memberi nama tiap anggota dan mengatur penampilannya (kulit, rambut/hijab, atasan, bawahan, sepatu, aksesori; bisa diacak, ekspor/impor JSON). Tab Pengaturan untuk kualitas grafis (Desain sampai Ultra HD), lingkungan luar & suasana, label, kamera, dan kurangi gerakan.

      Menggerakkan kamera

      Menyambungkan ke Claude Code

      1. Buka terminal di folder _app_padev_studio_3d.
      2. Sekali saja: jalankan node setup.js (memasang pemantau di Claude Code).
      3. Jalankan node server.js lalu buka http://localhost:4545.
      4. Pakai Claude Code seperti biasa. Setiap divisi punya 3 anggota tetap di mejanya. Saat Kepala menugaskan, satu anggota dipanggil ke Ruang Pimpinan (lantai 2) untuk brief, lalu kembali ke mejanya dan bekerja; setelah selesai ia melapor lagi ke Ruang Pimpinan.

      Kalau halaman dibuka tanpa server, kantor berjalan dalam mode demo.
